## 🎯 Quick Test (5 minutes)

### Step 1: Login as Admin
1. Go to: http://localhost:3000/auth/login
2. Login with your admin credentials

### Step 2: Upload Your First Image
1. Go to: http://localhost:3000/admin-public/gallery
2. Click **"Upload Image"** button
3. Select any image from your computer
4. Enter a title (e.g., "Test Image")
5. Enter a description (optional)
6. Make sure **"Publish immediately"** is checked
7. Click **"Upload"**
8. ✅ Image should appear in the grid!

### Step 3: View on Public Page
1. Go to: http://localhost:3000/images
2. ✅ Your uploaded image should be visible!

### Step 4: Try Other Features
- Click the **pencil icon** to edit
- Click the **crop icon** to crop
- Click the **eye icon** to unpublish
- Click the **trash icon** to delete

## 🐛 Common Issues

### Images not uploading?
- ✅ Check you're logged in as admin
- ✅ Verify file size is < 10MB
- ✅ Ensure file format is supported
- ✅ Check backend is running

### Images not showing on public page?
- ✅ Verify image is published (no red badge)
- ✅ Check both servers are running
- ✅ Refresh the page

### Can't access admin page?
- ✅ Make sure you're logged in
- ✅ Verify you have admin or staff role
