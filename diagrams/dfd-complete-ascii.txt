PROCESS DETAILS:

3.1 - Validate Donor Eligibility
    Input:  Donor ID
    Check:  • Last donation date (minimum 3 months gap)
            • Medical conditions
            • Age (18-65 years)
            • Weight (minimum 50 kg)
            • Current health status
    Output: Eligibility status (Approved/Rejected)

3.2 - Record Donation Details
    Input:  • Donor ID
            • Blood group
            • Units collected
            • Donation date
            • Location
            • Storage location
            • Notes
    Output: Donation record created

3.3 - Create Blood Pack
    Input:  Donation record
    Process: • Generate unique pack code
             • Set collection date
             • Calculate expiry date (42 days)
             • Set status to AVAILABLE
             • Link to donation and donor
    Output: Blood pack record

3.4 - Update Donor History
    Input:  Donation record
    Update: • Last donation date
            • Increment total donations count
            • Recalculate eligibility
    Output: Updated donor profile

3.5 - Link to Event (Optional)
    Input:  Event ID (if donation during event)
    Process: Link donation to event
    Output: Event-linked donation

3.6 - Generate Donation Confirmation
    Input:  Complete donation record
    Output: • Confirmation receipt for donor
            • Donation record for staff
            • Trigger certificate generation

PROCESS DETAILS:

5.1 - Receive Blood Request
    Input:  • Recipient name
            • Recipient type (Person/Organization/Hospital)
            • Blood group required
            • Units needed
            • Contact details
            • Urgency level
    Output: Blood request record

5.2 - Check Blood Availability
    Input:  Blood group, units needed
    Query:  • Search available blood packs
            • Check expiry dates
            • Verify pack status (AVAILABLE)
            • Calculate available units
    Output: Availability status and pack list

5.3 - Select Blood Packs
    Input:  Available blood packs
    Logic:  • FIFO (First In, First Out)
            • Prioritize nearest expiry
            • Match blood group exactly
            • Select required number of units
    Output: Selected blood pack IDs

5.4 - Create Issuance Record
    Input:  • Request details
            • Selected blood packs
            • Staff ID (issued by)
    Create: • Generate unique issue code
            • Record all details
            • Link blood packs
    Output: Issuance record

5.5 - Update Blood Pack Status
    Input:  Selected blood pack IDs
    Update: Change status from AVAILABLE to USED
    Output: Updated blood packs

5.6 - Update Inventory Summary
    Input:  Blood group, units issued
    Update: • Decrement available count
            • Increment used count
            • Update timestamp
    Output: Updated stock summary

5.7 - Generate Issuance Receipt
    Input:  Complete issuance record
    Output: • Receipt for recipient
            • Confirmation for staff
            • Audit trail entry

PROCESS DETAILS:

4.1 - Add/Update Blood Pack
    Input:  • Pack code
            • Blood group
            • Collection date
            • Expiry date
            • Storage location
            • Donor ID
            • Donation ID
    Output: Blood pack record created/updated

4.2 - Monitor Expiry Dates
    Process: • Daily automated check
             • Query all blood packs
             • Compare expiry dates with current date
             • Identify packs expiring within 7 days
             • Identify expired packs
    Output: List of expiring/expired packs

4.3 - Update Pack Status
    Input:  Pack IDs and new status
    Update: • Change status (AVAILABLE → EXPIRED)
            • Record status change timestamp
            • Maintain status history
    Output: Updated blood packs

4.4 - Calculate Stock Summary
    Process: For each blood group:
             • Count AVAILABLE packs
             • Count USED packs
             • Count EXPIRED packs
             • Calculate total
             • Update last updated timestamp
    Output: Updated stock summary

4.5 - Generate Stock Alerts
    Conditions: • Stock below minimum threshold (e.g., < 5 units)
                • Packs expiring within 7 days
                • Zero stock for any blood group
                • Unusual usage patterns
    Output: Alert notifications to staff

4.6 - Search & Filter Inventory
    Input:  Search criteria (blood group, status, date range, location)
    Query:  Filter blood packs based on criteria
    Output: Filtered blood pack list

4.7 - Generate Inventory Reports
    Input:  Report parameters (date range, blood group, etc.)
    Process: • Aggregate inventory data
             • Calculate statistics
             • Format report
    Output: Comprehensive inventory report

D8: Blood Stock Summary
    • Summary ID (Primary Key)
    • Blood Group (Unique)

    • Last Updated
